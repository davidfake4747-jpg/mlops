# Подготовка данных

Команды выполняются из корня `mlops`. Проверенное окружение — Python 3.13
на macOS. Для этой стадии не требуется устанавливать зависимости веб-сервиса.

## Окружение

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-data.txt
```

`requirements-data.lock.txt` фиксирует версии прямых и транзитивных зависимостей
проверенного окружения. На другой платформе доступность этих версий необходимо
проверить установкой и тестами.

## Первый импорт предоставленного архива

```sh
python import_data.py /путь/к/data-20261114T110354Z-1-001.zip
dvc add data
```

Импорт сохраняет исходные Excel-файлы без изменений в `data/` и создаёт
`source_manifest.json` с SHA-256 архива и каждого файла. Повторный импорт
того же содержимого допустим; отличающиеся существующие файлы не перезаписываются.
Это замена исходного набора преподавателя, а не дополнение к старому `data.dvc`.

## Локальное DVC-хранилище

```sh
dvc remote add --local -d local "$(pwd)/../.dvcstore"
dvc repro
dvc push
```

Настройка записывается в игнорируемый `.dvc/config.local`. `.dvcstore` расположен
рядом с репозиторием и сохраняет копию исходных данных и выходов пайплайна.
Это локальное хранилище текущего компьютера, не облачная резервная копия.
Не удаляйте его при очистке временных файлов.

## Восстановление на том же компьютере

После клонирования нашего репозитория и установки зависимостей:

```sh
dvc remote add --local -d local /полный/путь/к/существующему/.dvcstore
dvc pull
dvc repro
```

На другом компьютере одного Git-клона недостаточно: нужно передать исходный
архив или настроить общее DVC-хранилище, загрузить данные и предоставить доступ.
Для нашего репозитория общее хранилище пока не настроено.

## Стадии

`dvc repro` последовательно выполняет:

1. `prepare`: читает отдельные поля Domclick, сохраняет адрес, проверяет значения,
   исключает апартаменты по `params.yaml`, выявляет конфликты и удаляет дубли по ID.
2. `split`: отделяет holdout по нормализованным адресам с фиксированным seed
   и назначает каждому train-объекту validation-fold для GroupKFold.

| Файл | Содержимое |
| --- | --- |
| `features/all_features.csv` | Очищенные квартиры, признаки, цена, адрес и происхождение |
| `reports/data_quality.json` | Количества строк, дубли, исключения и сводная статистика |
| `reports/excluded_rows.csv` | Исключённые записи с причинами |
| `features/train.csv` | Train с колонкой `cv_fold` |
| `features/test.csv` | Holdout |
| `features/split_assignments.csv` | Принадлежность ID к split и fold; `-1` для holdout |
| `reports/split.json` | Размеры частей и проверка пересечений |

Train и holdout не пересекаются по ID и нормализованному адресу. Один дом
целиком относится к одному validation-fold. Доля holdout задаётся по группам
адресов, а не по числу строк. `id`, `address`, `source_file`, `source_row`,
`property_type` и `cv_fold` не являются входными признаками модели.

Дубли с конфликтующими признаками исключаются до разбора причины. Ошибка
структуры Excel останавливает обработку вместо создания незаметно неполного
датасета. Поддерживаются `.xlsx` с заголовками из предоставленной выгрузки;
другие форматы требуют явного адаптера. Нормализация адресов исправляет пробелы
и регистр, но не заменяет проверку спорных написаний одного дома.

## Проверки

Для предоставленного архива получено 78 квартир из 46 групп адресов.
360 повторных строк удалены, 2 уникальных объявления апартаментов исключены.
Train содержит 63 квартиры из 36 групп, holdout — 15 квартир из 10 групп.
Пересечений ID и адресов нет; размеры validation-folds — 13, 13, 13, 12, 12.
Это результат текущих данных и параметров, не требуемые размеры будущих выборок.

```sh
python -m pytest -q
dvc status
```

Тесты проверяют изолированное извлечение признаков, конфликты и дубли,
невалидные значения, сохранение разных типов комнат, отсутствие утечки по домам,
детерминированность разбиения и импорт архива. Используются искусственные
примеры без сети и внешнего хранилища.

Файлы из `data/`, `features/` и выходные отчёты не добавлять в Git.
Сохранять в Git `data.dvc`, `dvc.yaml`, `dvc.lock`, `params.yaml`, код,
файлы зависимостей, документацию и правила игнорирования.
